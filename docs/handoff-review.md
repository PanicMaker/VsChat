## 本次交付审计修复

- 微信自动收图统一采用 HTTPS 可信媒体地址、逐次重定向校验、受限流读取、超时与取消；阻止 HTTP、回环／私网地址及越域重定向。显示端不再在失败后回退远程图片 URL；所有导入记录也只展示本地 raster 图片缓存，避免打开备份即自动联网。
- 图片缓存改用独占临时文件及原子替换，正常 I/O 失败回滚并保留旧文件；恢复仍不覆盖已有缓存。数据库与媒体锁顺序保持一致。独立快审及 9 项故障测试通过；进程崩溃不保证微信双文件跨文件原子性，不支持硬链接的文件系统会在替换前保守失败，Remote SSH 需验收。
- 微信非默认 API 地址与 token 摘要一同绑定；恢复仅接受当前 token 对应的可信微信地址，旧凭据文件也需 token 匹配。API 请求拒绝重定向，避免消息正文被自动转发。该更严格地址约束仍需真实服务返回值验收。
- 预览 token 随视图销毁、替换和数据面板关闭失效；视图销毁或替换后的异步晚返回不再签发 token，数据面板关闭后的晚到预览由前端丢弃并撤销；已明确确认的恢复允许完成，防止把已提交数据误报为取消。
- 旧 SQL NULL 身份仅在归档投影中转为空字符串，原记录和旧备份不改写；重复恢复仍去重且不建立发送路由。
- 文件系统错误不再将私有暂存路径发到 Webview；失败／待确认分类保持原意。详细诊断仍只在宿主日志。
- 密集 Markdown 超过节点或深度预算时完整回退原文，避免静默截断尾部。
- 容量文案明确：导出／备份／恢复覆盖当前通道所有联系人和旧账号；容量总计为整个插件存储目录，隔离仅针对当前通道。
- 构建脚本不再忽略 WASM 复制失败，使用跨平台 Node 文件复制并在缺文件时终止，避免生成缺少数据库运行时的安装包。

## 数据兼容与升级

1. 升级前停止所有共用存储的本地／Remote 扩展宿主，将**整个 globalStorage 目录**复制到新的备份位置，并保证有容纳备份、临时数据库和索引的磁盘空间。不要仅依赖现有 `.bak`：它是首次快照，可能早于大量后续消息。
2. 所有共享写入窗口使用同一新版本并重载，不混用新旧写入者。历史继续读取，已有记录缺失的附件不会凭空恢复；旧无账号草稿保留只读。微信首次升级会忽略无凭据归属的旧全局轮询游标，重新请求服务端仍保留的消息并去重，不能保证追回服务端已删除历史。
3. 需要回退时先停全部宿主，单独保留升级后的整个目录，再恢复升级前的完整目录及匹配版本。回退会舍弃备份之后的本地变化，先导出需要留存的新消息；不要用过旧 `.bak` 直接覆盖当前库。
4. 消息与附件解密资料仍明文保存在扩展存储；便携备份包含私有内容及可能的附件 URL／密钥，分享导出与可恢复备份是不同格式。恢复不包含登录凭据、路由或 QQ 额度。缓存隔离不释放磁盘。

## 验收步骤

先用独立用户数据与扩展目录安装本地 review VSIX，避免同为 0.9.5 的包覆盖日常使用环境。以下命令仅供用户验收，开发过程中未执行安装或启动真实通道：

```sh
code --user-data-dir /tmp/vschat-review-user --extensions-dir /tmp/vschat-review-extensions --install-extension /Users/midas/VsChat/dist/vschat-0.9.5-review.vsix --force
code --user-data-dir /tmp/vschat-review-user --extensions-dir /tmp/vschat-review-extensions --new-window
```

关闭该隔离环境的 `vschat.autoUpdate`，保持 Bark 配置为空。先用虚构备份或离线样本验收，再由用户另行安排测试账号的真实收发；本次没有登录、发送真实聊天或推送。

1. 面板切换／重开，A→B→A 快切；草稿、引用和迟到发送结果归属原联系人。旧无归属草稿只读可复制；导入的联系人不能发送。
2. 两种快捷键、多行和中文输入法；失败／未知结果保留草稿，无自动重发；确认成功才清除对应草稿。用户真实发送前核对“发送给”和平台会话状态。
3. 同存储两个窗口读不同联系人：新消息只更新对应列表和未读，查看旧消息不跳底，聚焦并读到最新后只清当前会话；另一窗口清空后同步重置。仅在隔离库演练清空。
4. 日期／类型／特殊字符搜索、未加载引用上下文；不改变主时间线和已读。密集 Markdown 末尾存在，原始 HTML 不执行，代码复制空白保持。
5. 文件选择取消、文件过大、权限失败、目标切换、保存取消与重试；错误不暴露私有路径。QQ 无下载来源的文件明确不可保存。检查原生剪贴板和对话框。
6. 小备份预览取消不写库；确认追加；重复恢复不重复、不覆盖；销毁重开视图后旧 token 不可确认。包括图片缺失／坏图／部分失败。验证容量总计与隔离后文件仍存在、不宣称释放空间。
7. 经用户安排后，用真实微信／QQ 测试账号验平台文件与图片格式、会话过期、配额拒绝、断网恢复、代理、休眠唤醒；检查连接状态与未知发送结果，避免不核对即重发。Remote SSH 单独验路径、权限、缓存和多窗口行为。
8. 后续授权提交后观察托管 CI 是否实际执行测试并产出包。此步骤可能进入既有发布条件，不能把本地打包当作发布授权。
